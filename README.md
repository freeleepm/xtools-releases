## 选择安装包

| 系统 | 文件标识 |
| --- | --- |
| Mac Apple 芯片 | mac-arm64，DMG |
| Mac Intel 芯片 | mac-x64，DMG |
| Windows 64 位 | win-x64-setup，EXE |

以每个 Release 实际提供的附件为准。Mac 可通过“关于本机”确认芯片类型。

`unsigned` 为未签名预览版，需要手动安装，不进入自动更新通道。正式签名版本可在应用的更新页面检查、下载，并确认安装。请保留 SHA256SUMS.txt 核对下载文件。不要将账号、Token、证书或用户数据提交到本仓库。
